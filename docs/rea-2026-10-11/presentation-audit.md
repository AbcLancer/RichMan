## 范围与证据

检查实际渲染和操作链路：卡片、小神仙、问号路点、购地建造、角色反应、隐身、乐透、查看数据、相机和功能区收放。使用正式界面及鼠标/键盘事件；难以短时间走到的路点使用确定性场景设置。

原版依据为用户提供的实机图、`docs/screenshots/orig/`、原版头像/卡面/插画/语音和已完成的逻辑逆向记录。本轮没有新增原版运行追踪，因此不把动画秒数、资源编号的推测映射描述成原版确定规则。旧 `ui-audit.md` 的完成标记不能代替当前验收。

## 已确认并修正

| 部分 | 问题 | 本轮修正 / 证据 |
|---|---|---|
| 个人反馈 | 对手拾取路边物体、遇神仙、买卖股票可能覆盖本地提示；对手的神仙金额也弹到本地 | 棋盘上的动作继续显示，个人提示、音频和金额转盘仅发给当事人。逐项检查18类对手事件 |
| 角色表情 | 左下头像永远使用01；快照刷新会覆盖瞬时表情 | 奖励/收租使用03，受罚/付租使用02，休息使用04；奖励和付租与既有3D动作联动，表情到期恢复。原版图片可直接辨认表情；暂定2.6秒，不是已恢复的原版时长 |
| 卡片配音 | 卡名语音函数存在但没有接到实际使用事件 | 按原版卡片编号播放专用卡名语音；没有专用语音的卡保持无卡名语音，避免用通用台词冒充 |
| 小神仙语音 | 技能专用语音未接入；获取小神仙的第二个同名事件分支无法执行 | 合并获取分支，接入原版“平时”和“发特技”的对应语音及文字。技能语音只在当事人客户端播放 |
| 小神仙菜单 | 使用/放生呈现灰色默认按钮，容易误认为不可用 | 改为浅底、蓝边、红字，统一字号与点击音，保留单击菜单和整槽命中区；右键当前宠物按实例操作，名单变化检测也按实例识别 |
| 小神仙低能量 | 只有红 tint 和叹号，没有担忧表情 | 使用原版第二张 mini 表情，取消整体染红；实测小赌神的低能量与满能量画面。此资源用途依据图像内容判断，完整原版表达状态机仍待追踪 |
| 对白遮挡 | 世界对白会盖住小神仙栏及其他前景操作界面 | 前景面板打开时隐藏世界气泡，气泡剩余时间仍正常消耗；同时将气泡限制在屏幕内 |
| 卡片叠加数量 | 虽然设了底对齐，数量仍被 PanelContainer 放到中间 | 增加独立覆盖层，实际落在卡片左下角；截图核验×3位置及字号 |
| 建造/拆除 | 特效使用路点位置，未跟建筑位置一致 | 改用地产位置（含合并锚点）；建造/改建也加入角色高兴动作 |
| 金额转盘 | 原先只是整串随机数字，颜色与参考相反 | 六个独立红底黄字滚轮、金边、逐位停在结算金额；不再用每帧乱数更新整串。滚动时长仍是近似实现 |
| 模态交互 | 问号确认界面打开时，空格可穿透到GO | GO路径增加前景面板检查；实键验证确认之前不启动新移动 |
| 卡片说明 | 提示里暴露“原版String.txt编号” | 玩家提示只展示卡名、用途及当前不可用原因 |

## 复核通过的既有表现

- 42张卡的结果和九种小神仙的实际技能入口；小赌神打开1至6步选择，点3后前进3步；糊涂鬼/小穷神先选择对手。
- 五只持有小神仙对应身上1只、备用4格；头像边缘单击可以打开使用/放生，悬停有亮度变化。
- 问号：原版金框插画、填入实际数值的文字、点击确认、连续结果依次显示；普通游乐场路点使用提示而非问号弹窗。
- 建造：右侧底板与建筑卡面，一级工厂/一级重工厂/一级工业区分开命名；实际选择可建造、只结算一次、结束当前地块操作。
- 一级两格重工厂受怪兽/爆炸后拆回空地；二级降至一级保留合并。
- 隐身：角色材质半透、无无敌环、倒计时无神仙标记，到期恢复。
- 每月1日乐透结果能在未进入乐透点时显示，结果页不能下注，稍后自行关闭；拉霸单次下注、原版兔女郎结果表情和自动关闭。
- 查看股票/排行榜有实际内容，地产图点击恢复普通建筑；功能区收起仍留按钮，地图页可恢复展开。
- 相机拖动方向、GO重置跟随、对手掷骰/付租与步行类别音效不向本地音频播放器派发。
