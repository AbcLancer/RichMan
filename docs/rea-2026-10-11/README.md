## REA 反编译补充与纠正

- `431ea0` 初始化等级为 1；上限从类型表读取，当前能量写为 `int(上限)×5/10`，即整数截断后的约一半。此前“约 40%”与原版这条路径有差异；按最新要求列入原版对齐修改。
- `431f50` 直接证明满能量时不衰减。未满时减去 `更新量/(Pet_Consume_Days×24)`；只对当前出战宠进入该衰减/升级分支。备用宠虽也被更新，内部出战索引判断会挡住这一段。
- `4323c0` 的成长等级上限为 4，每次升级将成长累计字段归零。不能用一张包含三颗星的图表达“一星初始”，也不能把三颗星推断为等级上限。
- `41d120` 在尺寸×尺寸范围内遍历全部格子，清除建筑引用 `+30`、共享锚点 `+14` 并去掉建造标志。结合 `41e110`，降到零级确实拆为分离空地；是否还能跨尺寸降级到另一类建筑，应按各升级路径分别核验。
- `41ee80` 不是宝石组合表，是分配卡片实例并标记占用。`41f110 / 41f160` 是同步命令包装。审计时仅按调用关系给入口命名会误导后续实现，相关旧疑问已加说明。
- `439bf0` 的动作类型 3 将给定步数写入移动组件（`423250`），与改向/常规掷骰是不同分支。该函数**不创建步数选择窗口**。小赌神最终调用骰子卡并传入参数，但选择器应追上层 UI 调用者，不能在看到卡片共用入口后就宣称窗口一定弹出。
- `436230` 根据动作类型检查体力及状态 2/3/4；不能将它误当成所有投资行为的统一条件。`4364a0` 则明确排除状态 11，说明隐形保护需要按实际权限入口追查。
- `431340` 的伤害分支先查无敌状态 1，再查隐形状态 11，任一存在都跳过扣体力。隐形免伤由读取独立状态实现，并不是同时写三个状态；免租仍要独立核对。
- `434350` 体力变为负值时进入 `436a10` 的医疗/异常路径；恢复时会把体力压到配置最大值。`433e20` 在特定住院子状态且体力等于最大值时调用恢复标志处理。完整出院位移和渲染隐藏仍需要继续查，不能将恢复标志函数 `4369d0`误叫作“医院出院函数”。
- `428a00` 按动画推进距离逐段移动，遇到道路道具调用 `42be40` 删除；`42be40` 移除道具管理实例并把道路道具索引改成 -1。这支持清除卡逐段执行，而不是一开始就把所有路点事件立即抹掉。
- `41fa20` 改建卡由选项参数算出类型 `选择%3+3`、尺寸 `选择/3+1`、等级 1，再排入改建动画；它不是随机改为普通低级住宅。与九种特殊建筑文案可交叉核验。
- `41f080` 宝石增强读取卡片定义 `+13c`：值为 999 时设置增强标志，其他值则换成指定卡类型；值 -1 被选择逻辑排除。完整定义表的装载和索引需要继续核对，不能把所有 999 误当作土神卡。
- 上述定义表随后已完成核对：装载函数实际入口 `41e460` 从每条 `0x240` 字节记录尾部整数读取强化目标，再减 1 写入 `+13c`；原文件 1000 表示增强标志，0 表示不可增强；地雷索引另强制设为 -1。八份 `mainmenu/cardset/*/card.crd` 已保存原始 SHA-256、字段偏移与 42 卡映射，见 [card-enhancement-resource.json](card-enhancement-resource.json)。换卡映射为：升级→天使、怪兽→恶魔、购地→土地公、免费→财神、无敌→隐形、飞弹→核弹、查税→穷神、抢夺→衰神。财神/福神/穷神/衰神/天使/恶魔/请神、暴走、涨价/降价、冬眠、红/黑、查封、隐形则写增强标志。是否某张牌在某地图实际可获得，仍取决于地图启用及库存配置。
- 乐透 UI `44e120` 只接受未被购买的号码，并用本次窗口 `+f8` 标志阻止再次购买；窗口初始化 `44d740` 会清掉本次选择标志。计数函数 `429ca0` 遍历 12 个号的全局归属，选号 UI 限制个人累计少于 6 个。不是整个游戏只能选一次。开奖结果函数 `44e0a0` 区分有中奖者/无人中奖，触发不同文案和获奖反馈。
