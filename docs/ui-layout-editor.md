# 界面对齐与手动校准

## 使用方法

双击项目根目录的 `EDIT_UI.bat`，或正常启动后按 **F10**。

1. 按 F10 关闭工具，进入要调整的界面；再按 F10 打开。
2. 搜索画面里的文字、图片文件名或节点名称，点击列表中的项目。选中的控件会有红色边框和半透明红色覆盖；列表显示文字／图片及父节点，完整路径可悬停查看。
   工具挡住要查看的位置时，按住顶部「界面校准 · 拖动此处移动」标题拖动整个面板；红色标记会留在被选中的控件上。
3. 调整横纵坐标、宽高和字号，立即查看效果。
4. 点击「保存全部」。下次启动会自动读取 `game/data/ui/layout-overrides.json`。
5. 「重置选中」恢复该控件最初的布局；再次保存才会将这个重置写入文件。
6. 「导出检查」生成 `docs/ui-layout-audit.json`，包含文字、边界、图片尺寸和素材路径。

坐标相对于父节点。窗口尺寸改变时，调整值按父节点的尺寸比例应用。容器会自动排列子项；这类项目请调整父容器，或调整子项字号。工具不会强行覆盖容器排版。

原版背景中的装饰、标题及部分文字已经合并在一张图片里，不能作为独立控件拖动；覆盖其上的按钮、说明、数值及图片可以调整。游戏内动态窗口需要先打开，才会出现在列表中。工具按结构路径识别控件；大幅改动界面节点结构后，旧配置可能需要重新校准。

## 本轮调整

直接转换原版 `mainmenu` 目录的 469 张 TGA，保留透明度。四个开局页面使用真实背景、按钮、六边形地图、地图插画、角色立绘和载具图，按原版 800×600 坐标布局；宽屏两侧留边，避免图片变形。地图说明使用可换行文字，角色设置实际影响人数、资金与点券。

修正了商店标签行的位置、乐透数字点击区域、拍卖字段、股票列宽、聊天栏及角色面板按钮边界。长文本按区域适配字号并在必要时省略，缩小的文字可悬停查看全文；容器内的段落保留自动换行和高度计算。

原图上通关奖杯依赖真实通关记录，当前没有对应存档数据，因此不会伪造。读取游戏和卡片设置仍显示当前功能状态；游戏时间与难度只提供已支持的选项。这次没有实现这些尚缺失的玩法。

## 检查与复查

启动 Godot 时传入用户参数 `--ui-review`，会用真实运行控件生成界面检查截图，保存在 `docs/screenshots/ui-review/`；包括四个前端页面、联机/系统/大厅、游戏 HUD、聊天、暂停、赌场、乐透、拍卖、股票、商店、宠物、仓库、新闻、购买确认、骰子、建筑选择、卡片菜单、对话与校准工具。报告包含长名字和大金额的边界检查。这些是代表性状态，不涵盖每一种游戏事件组合。

本轮检查覆盖 33 个界面状态，已检查 1280×720 与缩小窗口下的截图。记录中的可见文字、按钮和图片均未超出视口，已有逻辑自测 280 项通过。检查还会验证开局设置传递、菜单面板重复打开以及校准值写入再读取。校准验证使用临时测试文件，不修改你保存的布局。自测退出时仍有资源清理警告，未将其作为界面验证通过的依据。

原版位图里的文字仍受原始分辨率限制；本轮解决比例、布局和动态文字清晰度，不将原版低分辨率图片描述为重新绘制的高清素材。

## 2026-09-28：选中标红、面板拖拽与日历修正

红色标记位于独立覆盖层，不修改控件颜色，不参与容器排版；关闭工具或目标控件隐藏／销毁时自动隐藏。拖动标题移动校准面板，屏幕边缘会限制位置，避免标题被拖出视口。

日期栏现在显示「日/月」，每月 30 天，1 月 30 日之后是 2 月 1 日；一年为 12 个月。悬停日期栏可查看年份、当前物价指数和空地价格。原有每月指数 +1 的结算现在有五秒提示，并继续影响地价、建筑租金；尚未建设的空地租金也已补上物价倍率。每月 +1 的幅度仍是现有推定值，未新增原版涨幅证据。

新增 `--workbench-calendar-review` 检查通过 22 项，覆盖真实鼠标标题拖拽、红色选中、边缘限制，30 天换月、年末、月度指数与价格、同月去重及快照恢复。截图位于 `docs/screenshots/workbench-calendar-review/`。原有核心 310 项通过。

## 二级界面校准

修正了扫描范围：买地、升级及商店购买的确认框位于独立 `ConfirmationLayer`，此前只扫描主界面层，导致这些控件不在列表里。现在同时扫描独立弹窗及游戏菜单层，保持已有主界面校准路径不变。红色标记和工具位于这些界面之上，输入拦截用的透明全屏遮罩不进入校准列表。

使用方式：

1. 先打开买地提示或其他需要调整的窗口，再按 F10。
2. 搜索「买地」或「确认提示正文」「确认：是」「取消：否」，选中即可查看红色范围。打开、关闭窗口后列表会自动更新，也可以点「刷新」。
3. 调整确认框的坐标、尺寸，或正文的字号，再点「保存全部」。拖动标题可将工具移开。

容器管理的子按钮位置和尺寸不提供直接修改，其四个几何输入框会禁用；需要选中外层确认框调整，文字控件仍可以调整字号。买地、升级、卡片与商店确认共用同一个确认框，因此该框的布局调整也适用于它的其他用途；重置框后恢复原有自动定位。

`--workbench-popup-review` 18 项通过，覆盖买地提示自动收集、正文及按钮标红、语义搜索、弹窗层级、保存和重新打开、每帧定位保持、关闭清理、重置与独立游戏菜单。校准保存验证使用临时测试文件，没有覆盖用户的布局文件。日历及工具拖拽回归 22 项、卡片流程回归 49 项通过。截图位于 `docs/screenshots/workbench-popup-review/`。
