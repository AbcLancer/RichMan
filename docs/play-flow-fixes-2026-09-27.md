# 实际试玩与流程修复（2026-09-27）

## 本轮实际操作

使用游戏窗口里的鼠标和键盘，走过主菜单、单人新游戏、埃及地图、角色设置、掷骰、购买地块、支付租金、暂停菜单、保存、返回主菜单、读取存档、再次掷骰。没有完成整场胜负，也没有人工遍历七张地图的所有随机事件。

中国地图的房型选择等低频落点，另用真实界面点击配合确定的对局状态检查，避免等待随机骰子。检查代码在 `game/scripts/ui/play_flow_review.gd`，截图在 `docs/screenshots/play-flow-review/`。

## 修复

- ESC 无弹窗时打开游戏菜单。返回主菜单需要第二次确认，不再直接销毁对局。已有弹窗时先关闭最上层弹窗。
- 单人暂停后按键或点击恢复；恢复用的输入被消费，避免同一次空格又掷骰。离开时清理暂停状态，下一局正常运行。
- 房型选择保留本次建造机会，传入实际地块和玩家编号；选择期间隐藏旧购买/建造确认框与 GO，防止覆盖。选中房型后正确建造、扣款并恢复行动。
- 放宽房型卡片，名称、联地数量、造价分行显示。
- 单人“读取游戏”接入实际存档。ESC → 保存游戏；主菜单 → 单人游戏 → 读取游戏。当前为一个存档位，不是原版多存档选择界面。
- 保存对局、电脑玩家、精灵、手牌、状态、地产、股票、拍卖、彩票、待执行爆炸及随机数状态；补齐原快照遗漏的物价/月份/道路生成时间等状态。
- 写入临时文件后替换存档，并保留上一份 `.bak`。缺失或基本格式错误的存档在切换对局前拒绝读取。
- 退出时关闭建造、卡片选目标、商店、拍卖、赌场、彩票和股票界面，回到真正的主菜单。
- 修复读档/换地图后路边物体仍引用上一局已释放模型的脚本错误；清理道路物体与事件图标缓存，并在重建时立即移除旧场景节点。
- 停止的模拟不再驱动电脑玩家；暂停时拒绝游戏动作。
- 单机不发送没有接收者的大厅、开局和状态 RPC。断线清理延后至连接轮询结束；复查已消除带有大厅广播调用栈的错误，但进程同时退出时仍有一条 ENet 底层通道提示，尚未完全解决。
