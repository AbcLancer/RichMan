## 2. 逐张截图里的**其它**细节（还没做）

### 2.1 底部手牌条（`卡片栏.png` / `使用卡片.png`）
- ✅ **卡面自带的**：左上角圆形徽章数字 + 顶部白底标签条（卡名）+ 下方插画
  → 我们的 `assets/card/<id>.png`（128×128）**已经是这个完整卡面**，无需另做标签条。
- ⚠️ **位置**：原版手牌条**紧贴左下角角色面板右侧**开始排，不是屏幕居中。
  我们的是「在角色面板与小地图之间自适应居中」。
- ⚠️ 原版手牌里**同一种卡会叠成一张并标数量**（如「×2」），我们已有 ×N 角标 ✅。

### 2.2 右下角**股票面板**（`使用卡片.png` / `喂食功能.png` / `小神仙语音.png`）
原版右下方**常驻一个股票行情面板**：
```
名称      股价   持股   %
钻石集团   33.2   2000  +20
恐龙世纪   31.6      0   -4
新土地     48.1      0   -1
美丽音乐   14.3      0    0
阿里巴巴   18.9      0   +2
```
→ **股票系统在埃及（工业关）也有**，而且行情面板是对局常驻 UI。
我们**完全没做**（`uitex/buystock/` 素材已在库）。属于体检报告里「零实现的大块」。

### 2.3 **拉霸（老虎机）**界面（`老虎机.png`）
原版：从**屏幕左侧滑出**一个粉色面板 —— 兔子女郎形象 + 3 个滚轮 + 「**请投注**」（`Info.txt` 66）
+ **三档下注按钮 `+1000` / `+5000` / `+10000`**（左上是 `EXIT`）。
我们是「直接结算给钱」，**没有界面**。素材 `uitex/labar/` 已在库。

### 2.4 **全局事件插画**（`全局事件.png`）
原版：**全屏插画框**（浅黄绿描边）+ 一行文字，例：
「**经济萧条，所有房租下降17%。**」（图里是楼房 + 红色下跌箭头）
→ 对应体检报告里「新闻真身 = 甲类 19 条带功能 + 插画」。素材 `samples/news/`（38 文件）已在库，
我们只做了「给一笔钱」的简化版。

### 2.5 **角色/小神仙台词气泡**（`小神仙语音.png`）
原版：浅蓝白**说话气泡**（`uitex/other/saybk.tga`）浮在角色/小神仙旁边，
例「我是人见人爱的小财神」。
我们目前是顶部 toast（纯文字标签），**不是气泡**。✅ 素材已入库 `assets/ui/shop/saybk.png`。

### 2.6 **其他玩家的名牌**（`收取到过路费.png` 红框 / `小神仙商店.png` 左侧）
原版在世界空间里显示别的玩家的**名字 + 现金**（如「巴克力 / 嘎加隔 / 258」「阿土伯 / 亚历山大 / 250」）。
我们只有当前玩家的顶栏信息 + 右侧头像列。

### 2.7 顶部状态栏（通用）
原版顶栏（1024 native）：`现金` `存款` `房产数` `点券` `徽章` `天数/难度` `暂停` `放大镜` `电脑`。
我们的顶栏项数一致 ✅，但**第 2 项「存款」恒为 0**（存款系统未做）。

### 2.8 卡片栏里的**徽章数字**（`使用卡片.png` 红框特写）
原版**大卡面**（使用卡片时左侧那个放大特写）左上角的圆圈数字 = 卡片徽章（我们已有 `badge` 字段），
右上角还标了**卡名**。→ 「使用卡片时的左侧大特写」我们**没做**。

## 3. 结论与优先级建议

**本轮已对齐 8 项**（老板直接点到的卡片商店 + 精灵屋面板全部解决）。

**剩下的大块**（按「牵动面」排序，与 `docs/alignment-gap.md §5` 一致）：

| 优先 | 项 | 为什么值得先做 |
|---|---|---|
| **P0** | **股票 / 公司系统**（含右下角行情面板） | 原版**常驻 UI**，且是红卡/黑卡这两张最后没生效的卡的依赖；`Initvar_r.txt` 25 个参数 + `Aiji.txt` 每家虚拟公司资产全都录好了 |
| **P1** | **拉霸界面**（`uitex/labar/` 素材齐） | 埃及有 2 格拉霸，界面是现成底图 |
| **P1** | **全局事件插画**（`samples/news/` 38 文件 + `Info.txt` 甲 19 条） | 现在只有 toast，插画一接上就「像原版」了 |
| **P2** | 台词气泡 `saybk.tga` / 其他人名牌 / 手牌条位置 / 使用卡片大特写 | 都是**表现层微调**，成本低、观感提升明显 |
