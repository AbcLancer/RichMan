# 卡片与小神仙测试指令

更新：2026-09-27。适用于当前项目的单人调试运行。

## 怎么添加

进入单人对局，打开右下角聊天栏，在输入框输入指令后按回车。指令结果会显示在聊天记录和屏幕提示中。

|指令|用途|
|---|---|
|`/help`|查看指令说明|
|`/card 飞弹卡 3`|添加三张飞弹卡，也可写英文 ID 或原版编号 27|
|`/cards 1` … `/cards 9`|按每页五种添加全部 42 种卡片|
|`/cards clear`|清空手牌和手牌锁定，方便测试下一组|
|`/pet 小财神 4`|添加四级小财神；已有同类时设置等级，不新增第二只|
|`/pets`|列出全部九种小神仙名称和英文 ID|
|`/pets clear`|清空小神仙背包及出战状态|
|`/petready`|令当前出战小神仙饱食度达到 100，清除技能冷却|
|`/credit 1000`|设置测试点券，技能依然会按正常规则扣费|
|`/money 500000`|设置测试现金|
|`/goto 10`|移到指定道路编号，不触发落点事件|

手牌仍受五种卡片上限和锁定保护约束；小神仙背包仍最多五只。测试下一组之前可先清空。
这些指令只允许没有远程玩家连接的本地调试房主使用；普通联机操作仍通过房主验证。

## 怎么测试小神仙

1. 输入 `/pet 小财神`、`/credit 1000`、`/petready`。
2. 点击左下角角色面板中的精灵栏，打开小神仙仓库。
3. 点击小神仙名字切换出战；仓库现在能显示、选择第五只。
4. 点击“发动技能”。饱食度不足、冷却、点券不足、住院、睡眠或没有有效目标都会给出提示。
5. 正常喂食：点击手牌，选择“喂食”。两次喂食可把空饱食度补到 100；喂食不会直接提升等级。

只显示当前出战小神仙的跟随模型。背包其他小神仙仍被保存，可以随时切换。
沿用了原有的落点自动发动机制，也增加了主动按钮；自动发动可能先消耗饱食度并进入冷却。

|名称 / 英文 ID|本轮验证的技能结算|
|---|---|
|小穷神 `qiongshen`|对手的租金支出加倍状态|
|糊涂鬼 `hutu`|附近对手睡眠、停止移动|
|小恶魔 `emo`|对手建筑降一级|
|小财神 `caishen`|主人限时免租|
|小土神 `tushen`|对手地产转移给主人|
|雪精灵 `jingling`|自己的建筑免费升级；升级失败保留消耗|
|花仙子 `huaxian`|主人限时无敌|
|小赌神 `dushen`|准备下一次遥控骰子效果|
|小怪兽 `guaishou`|选有精灵的对手攻击；被打走的是出战精灵时更新出战状态|

## 本轮修正的卡片差异

- 地雷：依原版说明和 `0x41ff10`，放在身后一格，随前进方向变化。
- 汉堡：按原版配置补 1000 体力，限制在体力上限内。
- 升级、怪兽：进入建筑地块选择，作用到选中的建筑。
- 改建：选择脚下自有建筑的新房型，不再由界面自动循环类型。
- 宝石：组合卡片，不再增加宝石计数。目前接入有反汇编依据的财神、福神、穷神、衰神四种组合，手牌以“★强化”区分。
- 诱拐：转移精灵后同步双方出战状态，同类合并，避免出现重复跟随模型。

## 验证范围与还原边界

结果保存在 [card-pet-audit.json](card-pet-audit.json)：42 张基础卡片各自使用独立地图状态，检查效果、住院时拒绝使用和锁定保护；九种小神仙通过实际界面指令和技能按钮检查施放、扣费、冷却、跟随模型。

本轮覆盖 197 项检查，全部通过；原有核心 310 项、卡片界面 49 项、游戏流程 26 项也通过。测试并不等于所有规则已与原版完全一致：

- 人工选点的最远距离、部分小神仙选目标策略及自动施放时机仍是当前复刻的推定实现。
- 宝石其他组合还未确认，当前会明确拒绝不支持的组合并保留卡片。
- 财神／穷神金额倍率与难度、地图的关系仍待追踪。
- 爆炸住院已有停止行动和倒计时，原版医院／救护车演出尚未完整复现。
- 诱拐同类精灵的等级合并沿用现有购买同类精灵的规则，未宣称已得到原版独立验证。

另以房主和两个独立 ENet 客户端验证了客户端切换出战精灵、主动技能、重复施放拒绝、一次扣费和远程状态／演出同步。关闭连接时仍有现有的 channel 0 发送错误日志，未将其算作已修复。
