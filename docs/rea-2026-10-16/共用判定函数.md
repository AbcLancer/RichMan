## 1. 十个判定函数逐个解读

### `FUN_00435620`（7 字节，**被 20 个门禁调用**）★★★

```c

```
**就是个 getter —— 取 `+0x1c0`**。
结合 `4364c0`（C06）里 `DAT_004e1b80 + DAT_004e2a84 * 0x1e0` 的用法：

> **`+0x1c0` = 玩家的「索引 / ID」**，`0x1e0` = 玩家对象大小。

### `FUN_0042bb70`（24 字节，6 个门禁）—— ⚠️ **反编译失真**

```c
void FUN_0042bb70(param_1, int n) { for (; n != 0; n--) { } return; }
```
**空循环** —— 但**调用处把它的返回值当地址用了**（`pos = FUN_0042bb70(...); plot = FUN_0042bb50(pos);`），
说明 **Ghidra 的返回类型推断错了**（`void`）。从 `421240` 的用法看，
它实际应该是**「从当前位置沿道路前进 n 格，返回目标位置的记录指针」**。

> ⚠️ **这是一条重要的方法论提醒**：反编译的**返回类型/参数类型是推断的**，
> 遇到 `void` 却在调用处被取返回值时，**要以调用处的用法为准**。
