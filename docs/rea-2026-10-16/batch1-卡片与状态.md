## ⭐ 附带收获：找到了 `card.crd` 的真实路径


结构体步长 `iVar9 * 0x230`（0x230 = 560）→ 具体字段布局**还需把 `card.crd` 解出来才能定**。

## C06 · 隐形

### 原版证据

**`FUN_004364a0`（26 字节）—— 「能否被攻击」判定**
```c
if (*(int *)((int)p + 0x3c) != 2) {
    if (FUN_00435fe0(p, 0xb) == 0) return 1;   // 查状态 11：未置位 → 返回 1
}
return 0;
```
**`FUN_004364c0`（84 字节）—— 另一处判定**
```c
if ((*(int *)(p + 0x1c0) == 0) || (*(int *)(p + 0x3c) == 300)) return 0;
if (p != &DAT_004e1b80 + DAT_004e2a84 * 0x1e0) {    // ← 不是「当前行动玩家」
    if (FUN_00435fe0(p, 0xb) != 0) return 0;        // ← 隐形 → 不可被攻击
    if (_DAT_00495460 <= *(double *)(DAT_00502edc + 8)) return 0;   // 时间判定
}
return 1;
```

**读出来的东西**：
- **隐形 = 状态 11**，用 `FUN_00435fe0(p, 0xb)` **查**（与 C05 的 `435f80` **写**成对）
- **`0x1e0` = 玩家对象大小**（`DAT_004e1b80 + 索引 * 0x1e0` 是玩家数组寻址）—— 这个数字以后有用
- **`+0x3c`** 参与判定（值为 `2` 或 `300` 时短路）；**`+0x1c0 == 0`** 时直接返回 0
- **两处查询都只证明「免伤 / 不可被攻击」，没有任何「免租」痕迹** ⚠️

### 我们的实现（实测）

```gdscript
3475:  e["invisible_until"] = time + float(c.get("seconds", 72))     # ✅ 只设自己，没有联动无敌/免租
2352:  if no_rent_until > time or invisible_until > time: ...        # ⚠️ 隐形被当成「免租」
4092:  return invincible_until > time or invisible_until > time      # ⚠️ 隐形被当成「无敌」
```

| 判定 | 结论 |
|---|---|
| 隐形是**独立状态** | ✅ 我们**已经是**（3475 行只写自己）—— 报告说的「同时延长无敌+免租」**已不成立** |
| 隐形 = **免伤** | ✅ 有原版证据，我们也做对了 |
| 隐形 = **免租** | ❓ **原版没有证据**（两处查询都只关「能否被攻击」）→ **我们多给了**，但**不能断言原版一定不免租** |

**→ 判定：`待议`**。差在「隐形到底带不带免租」，**原版证据不足**，需要再追
`+0x1c0`/`+0x3c` 的语义和其他查状态 11 的地方。**不建议现在动**。
