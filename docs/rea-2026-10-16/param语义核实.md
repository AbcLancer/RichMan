# param（`card.crd` 的 `+0x220`）语义核实 —— 两个「不能盲用」的结论

> 上一轮（C09）用 `param` 修好了清除卡与飞弹卡的范围。**本轮想把它推广到其他卡，
> 结果核实出两个反例，所以停手了** —— 记在这里，避免以后有人又想当然。

## 结论一：`param = 0` **不是**「该地图禁用这张卡」

**曾经的推测**：太空图里四神/天使/恶魔/改建/升级/怪兽/购地/涨价/降价/免费/红黑/查封/诱拐/
查税/均富 的 `param` 全是 0 → 看着像「这些卡在太空图被禁」。

**核实方法**：对比七张地图的**卡名表** `mainmenu/cardset/<地图>/card.txt`。

```
aiji 43 行 · china 43 行 · island 43 行 · japan 43 行 · paris 43 行
space 43 行 · train 43 行        ← 七张图行数完全相同
diff aiji/card.txt space/card.txt → 无差异
```

→ **七张地图的卡池一模一样**（连顺序都相同）。如果「`param = 0` = 禁用」，
原版不会把 42 张卡的名字都留在太空图的卡表里。

**所以 `param = 0` 另有含义。看太空图的分布规律**：

| 太空图 `param ≠ 0` 的卡 | 太空图 `param = 0` 的卡 |
|---|---|
| 步卡(10) · 转向 · 暴走(10) · 骰子(10) · **地雷(30)** · 路障(10) · 无敌(10) · **飞弹(25)** · 冬眠(3) · 复制(7) · 宝石(6) · 汉堡(15) · 清除(9) · 停留(8) · 隐形(100) · 核弹(100) | 四神 · 天使 · 恶魔 · 改建 · 升级 · 怪兽 · 购地 · 涨价 · 降价 · 免费 · 红黑 · 查封 · 诱拐 · 查税 · 均富 |

- **有值的一侧全是「位置 / 移动 / 道路」类**（要算格数）
- **全是 0 的一侧全是「目标 / 地产 / 建筑」类**（不按格数算）

→ **更可能的解释**：**太空地图没有「街道 / 地产」这个概念**（格子结构和别的图不同），
所以那些卡的「范围」**无从谈起 → 记 0**。
**这不是「禁用」，而是「这个字段对该卡在该图无意义」。**

**⇒ 不动代码。**（如果误按「禁用」实现，太空图会凭空少掉十几张卡。）

## 结论二：`param` **不是**统一的「范围/步数」——不能套到所有卡

想把 `param` 推广时，撞上两个反例：

| 卡 | 原版 `param`（china） | 我们的实现 | 冲突 |
|---|---|---|---|
| 穷神卡 | **2** | `c.get("steps", 30)` = **30 步** | 附身「30 步」，**不可能是 2** |
| 衰神卡 | **2** | `c.get("steps", 30)` = **30 步** | 同上 |
| 免费卡 | **8** | `c.get("steps", 20)` = 20 | 同量级但不等 |
| 隐形卡 | **100** | `c.get("seconds", 72)` = 72 秒 | 100 更像「全图范围」而不是秒数 |

- **清除卡（7）/ 飞弹卡（2）**：`param` 确实当**格数**用 ✅（已接）
- **穷神/衰神（2）**：如果 2 是格数，那「附身 2 格」显然不对；但如果 2 是**别的量**，
  就说明**这个字段的含义随卡而变**。

**⇒ 目前只能确定**：**`param` 是「该卡在该图的一个数值参数」，但它的单位/含义由每张卡自己决定。**
**不能统一解释为「范围」。**

**已安全采用的两处**（有独立证据支撑，不只是靠 `param`）：
- **清除卡**：C09 反编译 `FUN_004209c0` 看到「前进方向 + 长度」的用法 ✅
- **飞弹卡**：同样位置语义 ✅

**⇒ 其余卡暂不用 `param`。**

## 下一步该怎么做（给后来者）

要确定某张卡的 `param` 含义，**唯一可靠的路子**是**读那张卡自己的效果函数**
（`+0x21c`，地址表见 `42卡函数表.md`），看它**怎么用这个字段**。
光看数值分布（多大、几张卡共用）**猜不出来** —— 本轮就栽在这上面。

**优先级建议**：先做**用户最常碰到**的（步卡已通、骰子、路障、地雷、四神）。
