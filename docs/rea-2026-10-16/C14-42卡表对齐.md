# C14 · 42 张卡 —— 卡表对齐（数据层）

> 承接 `card-crd-解析.md`（原版卡片表结构）。本文做**数据层**对齐：
> **原版 `card.crd` 的 42 张卡** vs **我们的 `game/assets/card/index.json`**。
> 产出：`game/data/rules/card_alignment.json`（42 行完整对照）。

---

## 1. 好消息：**卡序、卡名、`badge` 全部对齐**

| 检查项 | 结果 |
|---|---|
| 张数 | 我们 42 / 原版 42 ✅ |
| **卡序一一对应** | **42 / 42 全对** ✅（含简繁差异，如「财神卡」vs「財神卡」，顺序完全一致） |
| **`badge` vs 原版 `+0x224`(tier)** | **42 / 42 全对，0 张偏差** ✅ |

所以**我们的卡表不是猜的**，是从原版素材按**同一顺序**构建的 —— 这一点可以放心。

---

## 2. ⭐ 坏消息：**原版的核心参数字段 `param`（`+0x220`）我们完全没用**

原版每条卡记录里有个字段 `+0x220`（我命名 `param`），**12 种取值**。
把它按地图展开后，语义就清楚了 —— **它是「卡的作用范围（格）」**：

| 卡 | `param`（七图） | 读法 |
|---|---|---|
| **清除卡** | `aiji/中国/海岛/日本/巴黎/铁路 = 7`，**太空 = 9** | 清前方几格 |
| **地雷卡** | `4 / 4 / 4 / 4 / 6`，**太空 = 30** | 放置/触发范围 |
| **飞弹卡** | `2`…，**太空 = 25** | 打击范围 |
| **路障卡** | `8`，太空 `10` | |
| **骰子卡** | `13`（埃及）/ `10`（其余） | |
| **汉堡卡** | `20`（埃及）/ `15`（其余） | |
| **隐形卡 / 核弹卡** | `100`（全图） | |

**✅ 33 张卡的 `param` 随地图变化** —— 这就是「**同一张卡在不同地图上范围不同**」。

### ⭐ 顺带发现：`param = 0` 就是「该地图禁用这张卡」

**太空地图（`space`）里，大量卡的 `param = 0`**：
四神卡（财神/福神/穷神/衰神）、天使、恶魔、改建、升级、怪兽、
购地、涨价、降价、免费、红卡、黑卡、查封、诱拐、查税、均富……

→ **`0` 应该表示「这张卡在该地图不出现/不可用」**，正是 C14 报告里要找的「**门禁**」。

---

## 3. 所以我们的差距（**这是 C14 第一处确定差异**）

| 项 | 原版 | 我们 |
|---|---|---|
| **卡的范围** | 按地图从 `card.crd` 的 `+0x220` 读 | ❌ **完全没用这个字段**；例如清除卡写死 `range(1, 8)` |
| **太空图的清除卡** | **9 格** | ❌ 我们给 7 |
| **太空图禁用的那些卡** | `param = 0` → 不可用 | ❓ **未核**（我们的卡池是不是每张图都一样？） |
| `badge`（星级/徽章） | `+0x224` | ✅ **已对齐 42/42** |

**结论**：**`param` 这张表我们从来没读过** ——
它同时承载了「**范围**」和「**该图是否可用**」两件事，**是 C14 的主干**。
