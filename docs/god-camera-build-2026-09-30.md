# 神仙、相机拖动与联合建造（2026-09-30）

- 路点福神附身现在发卡，并赋予 30 步免费建造；财神给钱、30 步免租；穷神扣钱、30 步房租加倍。金额范围与发卡数量复用 `config/Initvar_r.txt` 中对应神仙卡的参数。衰神仍为 30 步禁建。碰到新神仙时替换上一种步数附身。
- 角色头顶平时不显示姓名或现金。附身时显示 `uitex/effect/` 中对应头像以及绿色剩余步数。头像位置和尺寸按本轮原版截图缩小上移。
- 财神、穷神结算时出现红字金框的六位数字转盘。当前金框由 UI 绘制；转动节奏和边框仍是画面近似，尚未找到与原版转盘完全对应的素材和动画序列。
- 鼠标右键拖动画面转相机、左键拖动平移相机；右键短按仍可关二级界面或查看路点说明。平移后停止跟随角色，按原有跟随入口可重新对准角色。
- 已购空地抵达后直接出现右侧建筑选择卡。每个允许建造的类别列出三个占地档位（工业：工厂、重工厂、工业区；其他主题按 House.txt 等级表）；无法在已持有连续地块上落成的选项不可点。选项提交时把具体等级带给权威模拟并重新核算面积、价格和所有权。
- 小神仙能发动时使用其 `faceb` 表情图，右下出现原版 `icon1/icon2` 发光技能按钮，点按钮发动已出战小神仙技能。

校验：`--selftest` 312/312；`--god-camera-build-review` 17/17，截图见 `docs/screenshots/god-camera-build-review/`。旧的点击驱动全流程检查在本机窗口缩放下会把合成鼠标位置映射错，部分 UI 点击断言不稳定；本轮新增检查对玩法入口和界面节点直接验证。
