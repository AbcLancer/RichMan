## 一、本体技术画像

| 项目 | 实测值 |
|------|--------|
| 主程序 | `rich6.exe` 688 KB（x86 32bit, PE） |
| 资源包 | `gamedata.pck` 371.3 MB / 2143 文件 |
| 渲染 | `d3d8.dll`（Direct3D 8），800×600 16bit，默认全屏 |
| 视频 | `binkw32.dll`（Bink） |
| 音频 | `mss32.dll`（Miles Sound System） |
| 图像解码 | `ijl15.dll`（Intel JPEG Library） |
| 网络 | **`WS2_32.dll`（原生 Winsock）** |
| 架构 | **进程内 Server + Client 双模块** |

### 关键发现 1：进程内就是 C/S 架构

`r6log.txt` 完整记录了一次运行：

```
Init Server Data
----客户端开始load数据
Receive clmsg_load_progress: 0
LoadSceneOnCL: resmgr init / alleffects init / cardmgr init / housemgr init ...
----客户端load数据完毕
-----Server开始游戏, 人数=4-----
```

游戏内部早已把「服务端逻辑」与「客户端表现」拆成两个模块，用 `clmsg_*` 消息通信。
**单人模式 = 同进程跑 Server+Client；联机模式 = Server 在主机上跑，Client 收消息。**

→ 这意味：**玩法逻辑与网络传输本来就是解耦的**，重写网络层不需要动玩法代码。

### 关键发现 2：联机是标准 Winsock，非 DirectPlay

`rich6.exe` 的 IAT 以**序号**方式导入 `WS2_32.dll`，映射后：

| 序号 | 函数 | 判定 |
|------|------|------|
| 1, 2, 3, 4, 13 | `accept` `bind` `closesocket` `connect` `listen` | **TCP 流套接字** |
| 20, 17 | `sendto` `recvfrom` | UDP 亦可用 |
| 18, 115 | `select` `WSAAsyncSelect` | 同步/异步多路复用 |
| 10, 11, 24, 116 | `inet_addr` `inet_ntoa` `gethostbyname` `WSAAsyncGetHostByName` | **域名解析 → 当年有官方大厅服务器** |
| 名 | `WSASocketA` `WSARecv` `WSASend` | overlapped I/O |

### 「联机完全用不了」的根因

**不是游戏缺陷，是软星 2002 年的大富翁6 对战大厅（需域名解析登录）早已停服。**

- 「互联网」模式 → 连不上已关闭的大厅，必然失败
- 「局域网」模式 → 依赖 IPX 时代组播/广播 + 同网段，现代家用 NAT 网络下基本失效

→ 也就是说，**联机功能不是"修好"，而是"重做"**——这对我们是好事，因为可以按现代标准重新设计。

### 即时制核心参数（摘自 `Initvar_r.txt`）

```
推土机速度 / 救护车速度      = 2 格/秒
玩家静止多久进入睡眠          = 25.0 秒
相机缺省离地距离 / 俯角       = 12 格 / 40 度
无敌卡时效                   = 72 秒（即时制）  /  1 天（回合制）
隐形卡时效                   = 72 秒
冬眠卡时效                   = 10 秒（即时制）  /  10 天（回合制）
核弹卡爆炸范围 / 减体力       = 5 格 / 1000 HP
汉堡卡回复 / 地雷扣血         = 1000 HP / 1000 HP
拍卖地产等待                 = 15 秒
空地产格价格因子 / 租金系数   = 200 / 25
AI 原地停留                  = 6~20 秒（按难度）
AI 初始资产倍数              = 1× / 1× / 2×（简单/中等/困难）
```

> `_r` 与 `_t` 的对照说明：同一机制在即时制下以**秒**计量、回合制下以**天**计量，
> 且「1 天 = 24 秒」的换算关系被明写在注释里。**这是复刻即时制节奏的直接依据。**

## 四、可行性结论

| 目标 | 判定 | 依据 |
|------|------|------|
| 复用原始美术素材 | ✅ 可行 | PCK 已解包，TGA 标准格式可直接加载 |
| 1:1 复刻即时制玩法数值 | ✅ 可行 | 参数表全明文，无需逆向二进制 |
| 重做联机 | ✅ 可行 | 原生 Winsock + 内部 C/S 解耦，可整体换网络层 |
| 后续升级画面 | ✅ 可行 | 原作为 3D 场景（有 .max/.cvd/.pol），路径通畅 |

2. 美术源文件（`.psd`/`.max`）需 3ds Max / Photoshop 才能利用 → 高清化时确认环境
