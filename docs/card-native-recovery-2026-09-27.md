# 卡片原版逻辑查证与本轮修正

## 从哪里看原版

原版没有找到可以直接解包的卡片脚本。卡片执行代码编译在 `rich6.exe` 中。
本轮从原生登记函数 `0x00422270` 提取了 **42 张卡片的效果函数指针**，另提取
条件／电脑选点函数和辅助回调。原版文件没有修改。

- [42 张卡片函数索引](original-readable/cards-native/卡片函数索引.md)
- [地址及原版 EXE 校验值](original-readable/cards-native/dispatch.json)
- [详细阅读说明与伪代码](original-readable/cards-native/README.md)
- [可重复运行的提取工具](../tools/r6_disassemble_cards.py)

这些是明文汇编和人工解释，不是原始脚本源码。每个提取文件写明地址范围；部分范围
包含相邻辅助函数。登记表中的 `0x224` 槽包含电脑玩家选点，不能全部当成人类使用条件。

## 验证

- 核心自检：310 项通过，无失败。包含独立构造地图验证爆心、空间衰减、住院、无敌、
  核弹拆楼、快照保存、非法目标保留卡片、附身替换和穷神现金转移。
- 生产界面实际鼠标操作：49 项通过，覆盖点击地块发射飞弹与附身状态持续显示。
- 房主和两个独立客户端：收到发射队列、命中、建筑降级、住院和衰神状态；每端名牌一致。
  关闭测试连接时现有网络大厅偶尔产生发送到已关闭通道的日志，未计作特效同步成功证据。
- 42 张卡片基础执行测试仅证明执行／消费流程，没有证明42张规则全部与原版一致。

## 尚未确定或仍有差异

1. **人工选点的最远距离**：原版效果范围和电脑自动选点已定位；人类玩家选点的距离条件
   还没完全追到。飞弹暂用原版空间单位500作为候选距离，明确是临时推定。
2. **建筑范围末端**：建筑扫描和道路清理是两个函数。建筑扫描有 inclusive 循环及合并地块
   去重，确切起止端还需跟踪。当前使用中心前后各2路点，未宣称已经逐边界完全还原。
3. **宝石组合**：原版420460操作复合卡片编号，效果函数常有1／2倍分支；已接入财神、
   福神、穷神、衰神四种有依据的组合和强化手牌显示，其他组合范围仍待确认。不能把
   当前组合测试通过当作原版全部复合卡片已还原。
4. **改建／升级／怪兽目标**：原版17、18、19号函数已提取。升级接收打包的地块索引，
   改建有建筑类型参数；现已接入建筑选择和改建房型选择。选点距离、房型足迹特殊
   边界和电脑自动选择策略尚未逐项与原版完全对齐。
5. **原版状态互斥**：435f80清除12个状态再写入新状态；本轮先对齐四神互斥，其他状态
   的完整编号和互斥关系未全部落实。
6. **现金倍率**：穷神与财神通过41a950(3)取得金额倍率，本轮先使用原版配置金额区间。
   倍率与难度／场景的对应关系仍需追踪。
7. **其他卡片**：42张效果函数都已保存，但复制／宝石、改建、清除、涨降价／查封等
   的全部参数和特殊边界不能仅凭登记表确认，仍需逐函数翻译与对照。

后续查证可直接从索引对应的汇编文件开始，无需玩家逐张口述规则。
