# 路点说明、GO 与小神仙界面修正

## 改动

- 移除上一轮给空地额外加的绿色边框。空地仍使用原版地图记录的建造格坐标；原有地块占位底面和业主边框逻辑保留。
- 移除路面常驻的街道名、事件名、起点名，以及缺少模型时的路边物体名称。右键点击地块或事件格时，在点击处附近显示名称、价格／业主／租金或事件说明；再次右键关闭。玩家头顶的角色名与状态文字保留。
- 行走结束时若出现购地提示，GO 立即隐藏，避免骰子动画未结束时仍亮着但被提示框遮挡。处理或放弃地块后，GO 立即恢复。
- 出战小神仙饱食度达到 100 时，左下角头像内显示“技能”按钮，可直接发动。技能被冷却、住院等状态阻止时，点击后给出原因。
- 小神仙商店的名称与价格标签裁剪在各自槽位内；售出后头像、名称、价格与点击区域一并移除。四个货位分别验证，其他三只保持原位。

## 验证

- 核心自检：312 项通过。
- GO 操作回归：13 项通过，包括挂机醒来后连续两次掷骰，以及抵达空地时购地提示与 GO 的切换。
- 场景与商店回归：85 项通过，包括右键说明、无绿框与常驻路名、四个售出货位、小神仙技能按钮。
