# 挂机休息、路点模型、精灵屋与顶栏对照

## 本轮改动

- 挂机满 25 秒进入可主动取消的 `rest_until`。点击 GO 立即唤醒并尝试掷骰；即使体力不足，也会先解除挂机。冬眠、梦游、住院和外星人状态仍按各自计时处理。
- 休息时播放角色原版 `slee` 动画。业主处于挂机、冬眠／梦游、住院、外星人状态时，地产边框变黑，其他玩家经过该地产免付租金；状态结束后恢复。
- 从 `samples/roadobj/` 中原版 CVD 导出财神、福神、穷神、衰神、小偷、强盗、汉堡、宠物蛋、卡片、戒指、点券的动画模型。地图配置里另两类可生成物体（路障、炸弹／地雷）继续使用原版静态模型。生成脚本为 `tools/build_road_cvd_assets.py`，生成物位于被 Git 忽略的 `game/assets/original/road_items/`。
- 首次画面复查发现新 PNG 尚未导入时模型呈白色剪影；已完成 Godot 资源导入，并让 `PLAY.bat`、原素材启动器和资产对照启动器在启动前执行导入。
- 普通路点只显示原版地形中的石子路线与事件图标；未买空地改用原版建造格坐标绘制带绿色边框的独立方格。埃及传送点保留地毯。角色经过两端时，地毯承载角色飞行并旋转。
- 小神仙商店的出售位即时清空，重复购买同一货位被权威模拟拒绝。再次进店时按新货架显示。售价集中在 `game/data/rules/pet_shop_prices.json`，直接修改对应数字并重新启动游戏即可生效。
- 顶栏顺序为现金、股票市值、房产现值、点券、物价指数、日期、暂停、查看数据、系统功能。内部地价系数初始为 10，画面物价倍数显示为 1；每月系数上涨 1 时画面显示 1.1。房产现值记住买地与建造实际花费，并按当前物价倍数重估。

## 仍待原版核对

- `hutu` 和 `huaxian` 的购买售价没有原版实测记录。价格表中暂填 7 和 6，取自技能消耗点数，仅为占位；购买价格与技能消耗本来是两套数值。
- 外星人状态已有异常判定、禁行、黑色地边与免租规则；本轮没有定位到原版触发外星人绑架的完整事件链。
- 埃及传送端点的路线索引相邻、世界坐标远离；按现有地图数据接入了视觉飞行，飞行动作与持续时间仍需原版实机逐帧核对。
