# 世界特效、精灵跟随与角色动画

## 本轮接入

正常启动已有的原素材、高清修复或新版重绘启动器即可，三个版本共用本轮表现逻辑。

| 触发 | 场景表现 |
| --- | --- |
| 支付过路费 | 金币飞向收款玩家，付款和收款角色分别显示金额，并播放短暂表情动作 |
| 地雷、炸弹鬼、导弹与核弹伤害事件 | 原版爆炸动画网格、扩散冲击和烟雾 |
| 无敌卡生效 | 原版环绕光效跟随角色，依据权威状态出现和消失 |
| 获得小神仙、升级 | 星光提示；获得后在世界里持续跟随 |
| 精灵发动技能 | 对应精灵的原版施法帧、局部光环及角色动作 |
| 建筑升级、改建、降级 | 原版对应光效，放在事件地块位置 |

九种小神仙均有跟随和施法序列。按用户确认的规则，每个玩家只有当前选中的一只精灵跟随并发动技能，其他精灵保存在背包中，点击左下精灵栏可以打开仓库切换。喂食只增加当前出战精灵的饱食度。所有观察玩家都能看到相同的出战精灵；切换会移除上一只跟随精灵。飞行保留缓动、上下浮动和跟随滞后。

## 查到的原版处理方式

原始来源是 `D:\Projects\reference\Rich6\gamedata.pck`，本轮只读取原版。已解包的文件在项目 `samples/` 中。

- `effect1/wudi/1.cvd` 等 CVD 保存网格、顶点与变换动画，已沿用项目现有的逆向解析器转换。共恢复 16 个动画网格。
- 同目录 GBF 是可读的材质脚本。无敌、爆炸等使用 `SrcBlend = ONE`、`DestBlend = ONE`，并关闭深度写入，本轮使用相应的叠加发光材质。
- GAE 负责组合资源，可以取出它引用的 CVD、PAR 路径；PAR 粒子控制参数尚未完整还原。
- `uitex/pet/<精灵>/20..23.tga` 是飞行连续帧，`30..33.tga` 是施法连续帧。它们作为世界中的透明朝向相机精灵播放。
- `effects/smoke_1.tga` 包含烟雾小图；金币也复用原版图片。

可读材料保存于 `docs/original-readable/world-effects/`：GBF 明文、GAE 资源引用摘要及完整资源对应表。可复现转换工具为 `tools/build_world_effects.py`，输出目录为 `game/assets/original/effects/`。

**尚属重建的部分：** 精灵的播放速度、飞行轨迹、金币路径、烟雾发射节奏，以及部分光效的大小和亮度。未完整取得原版 GAE/PAR 的时序控制，不应把当前效果描述为逐帧完全相同。爆炸文件中的大屏幕闪光平面已限制场景范围，施法环缩到精灵附近，避免遮住整片地图。

## 角色动画优化

原 MD2 导出的动作键包含尾部空格，例如 `run ` 和 `sad `。原来的 `play("run")` 找不到对应键，导致跑步没有切换成功。本轮统一去掉动作键两端空白，12 个角色均可正确调用。

继续使用原始动作和原有帧间插值，加入站立、跑步、受击等动作间约 0.16 秒的过渡；转向由每帧平滑处理。跑步播放速度随移动速度改变，事件动作只播放一次，结束恢复当前移动状态。没有重做骨架或宣称增加了新的原版动作。

实现文件：

- `game/scripts/ui/world_effects.gd`：世界特效、各玩家精灵、状态清理。
- `game/scripts/ui/board_view.gd`：角色转向、动作反应、快照接入。
- `game/scripts/ui/original_mesh.gd`：动作键修正、播放速度、单次播放及过渡。
- `game/scripts/ui/animation_pose.gdshaderinc`：帧插值和姿态过渡。
- `game/scripts/ui/original_effect.gdshader`：原版发光特效材质。
- `game/scripts/core/sim.gd`：技能发动时间 `skill_at`，随已有玩家快照同步。
- `game/scripts/ui/app.gd`：将已有可靠联机事件送入世界表现层。

## 验证

`--effects-review` 用真实游戏场景检查九种精灵、跟随移动、技能动作、快照恢复施法、无敌结束、过路费、爆炸、角色动作恢复及临时节点清理，截图在 `docs/screenshots/effects-review/`。已检查高清修复和新版重绘的实际渲染。

`game/scenes/effects_network_probe.tscn` 提供本机 ENet 检查：一个房主和两个独立客户端，测试每位玩家的精灵、施法阶段、无敌状态、过路费与爆炸事件以及移除同步。测试端口为 31076。房主传入 `--effects-host`，两个客户端分别传入 `--effects-client`。

现有逻辑自测结果为 **290 项通过，0 项失败**。退出时仍有资源清理警告；不将这些警告描述为已修复。
