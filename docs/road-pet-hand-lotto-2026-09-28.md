# 路障、路点模型、手牌、精灵商店和乐透

本轮按用户提供的三张复刻截图及已有原版实机记录修复。

## 已完成

- 路障卡的候选路点保持绿圈；鼠标悬停的目标变红，移开恢复绿色。使用成功后，权威状态 `obstacles` 在地图上生成原版 `samples/roadobj/block/model.pol` 转出的路障模型；清除障碍后隐藏模型。
- 解出原版 `samples/roadobj/card/model.cvd` 和 `samples/roadobj/crystal/jiezhi.cvd`，以原版纹理和动画网格替换两种路边拾取物的发光球占位。资源由 `tools/build_road_cvd_assets.py` 再生；提取素材保持在忽略提交的 `game/assets/original/road_items/`。
- 平常隐藏角色脚下各自颜色的圆盘，仅在需要选角色使用卡片时显示候选绿圈与悬停红圈。
- 动态手牌格不再读取界面校准工具曾保存的 `PanelContainer1` 位置。三张不同卡按取得顺序分别显示，互不重叠；同种卡仍按已有规则合并并显示数量。
- 小神仙商店恢复接近原版的面板尺寸，名称与价格分放标签条两侧；点击头像打开购买确认，标签文字不再是购买按钮。商店控件采用稳定名称，旧的自动编号布局记录不再干扰底图与商品槽的对齐。
- 原版商店截图 `docs/screenshots/orig/records/小神仙商店.png` 明确显示雪精灵 40、小财神 100、小穷神 40、小赌神 80 点券。售价、确认文案、实际扣款统一按这四个数字。技能使用点数继续取 `Pet.txt`，与购买价分开。
- 乐透铅笔的笔尖跟随鼠标，选中号码后出现红色圆环；再次打开时清除上次的视觉标记。
