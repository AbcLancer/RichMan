# 卡片操作与相关问题修复记录

本轮针对用户实机反馈修复，共检查 42 张卡的效果入口，并用实际鼠标操作验证关键界面。原版文件未修改。

## 操作

- 卡片菜单选择“使用”，再点击地图上亮绿圈的路点或角色；附近玩家也可点击右侧可选头像。
- 选择目标期间右键或 ESC 取消；取消、非法目标和效果失败不会消耗卡片。
- 复制卡选择“使用”后，点击另一张手牌。
- 点击左下角角色面板的精灵栏，打开仓库；点击拥有的精灵切换出战。
- 重新启动现有启动器即可生效，原素材、高清修复和重绘版本共用这些逻辑。

## 验证

- 核心自测 **290 项通过，0 项失败**，包含全部 42 张卡效果执行和状态改变检查。
- `--card-flow-review` **41 项通过**：用真实鼠标输入检查购买确认及拦截、地图选点、对手选择、复制手牌、仓库切换和拍卖 PASS；同时检查失败保留手牌、喂食、唯一角色、移动动作、重复购买与售罄。
- `--effects-review` 通过：每位玩家只显示一只出战精灵，保留世界特效、动作过渡、快照施法恢复与节点清理。
- 一房主、两个独立 ENet 客户端通过：拥有两只精灵时只显示一只，远程切换与移除一致；客户端实际发送非法路点和合法路点请求，服务器分别保留卡和正确放置路障。
- 操作截图位于 `docs/screenshots/card-flow-review/`。核心自测退出时仍有既有资源清理警告。

## 原版规则待进一步核定

“效果能执行”不等于所有细节已经完全还原。本轮保留的附近范围为项目既有的 **5 个路点距离**；原版不同卡的精确范围、清除卡选点与前方范围的关系仍需实机对照。

另外在通读流程时记录了三项现有差异，未用未经确认的规则替换：宝石卡当前累积宝石，尚未实现原版完整组合强化；天使卡目前升级一处地产，而原版说明为一条街道；改建和部分地产卡仍存在自动选择地产或房型的旧逻辑。需要后续结合原版操作确认选择流程、强化数值和适用对象，不能把这几项记为已完全还原。

## 实现位置

- `game/scripts/core/sim.gd`：合法目标、效果执行、手牌处理、唯一角色、精灵出战、拍卖和货架。
- `game/scripts/ui/app.gd`：菜单、选目标输入、模态确认、精灵仓库和拍卖关闭。
- `game/scripts/ui/board_view.gd`：角色绿圈、路点标记、移动动作。
- `game/scripts/ui/world_effects.gd`：单只精灵跟随及快照切换。
- `game/scripts/net/net.gd`：客户端本地状态视图同步。
