## 追加：push 解决了（根因不是沙箱）

用户反馈「我自己 push 也报 `schannel: failed to receive handshake`」→ **推翻了我上面
「沙箱拦了对外 HTTPS」的判断**。真因是 **Git for Windows 的 schannel TLS 后端在 HTTP 代理后面
握手失败**（本机 `HTTP(S)_PROXY` 指向本地代理，端口每次不同）。

**解法**：换 OpenSSL 后端
```
git -c http.sslBackend=openssl ls-remote origin   # 临时验证 → 立刻列出 refs
git -c http.sslBackend=openssl push origin main   # 11 个提交一次推上去 7f7aaf5..9fc44e5
```
**已给本仓库固定**：`git config --local http.sslBackend openssl`（写在 `.git/config`，不提交）。
要覆盖所有仓库就改成 `--global`。

**当前状态**：本地 = 远端 = `9fc44e5`，**待推 0** ✅

教训：报错前缀是 `schannel:` 时，先查 **TLS 后端**，别往沙箱/凭据方向猜。
